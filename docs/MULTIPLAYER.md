# 🌐 Запуск мультиплеера по локальной сети

## Требования
- Node.js 14+ установлен на обоих компьютерах
- Оба компьютера в одной локальной сети

## Инструкция

### Шаг 1: На хост-компьютере (первый игрок)

```bash
# Запустить сервер (автоматически установит зависимости при первом запуске)
node server.mjs
```

Вы увидите:
```
╔═══════════════════════════════════════════════════════════╗
║                                                           ║
║   ⚔  КАРТЫ СУДЬБЫ - Сервер запущен!  ⚔                  ║
║                                                           ║
║   Локальный адрес: http://localhost:8080                  ║
║   Сетевой адрес:   http://<YOUR_IP>:8080                  ║
║                                                           ║
╚═══════════════════════════════════════════════════════════╝
```

### Шаг 2: Узнать IP адрес хоста

**Windows:**
```bash
ipconfig
```
Найдите "IPv4 Address" (например: 192.168.1.100)

**Linux/Mac:**
```bash
ifconfig
# или
ip addr
```

### Шаг 3: На втором компьютере

Откройте браузер и перейдите по адресу:
```
http://<IP_ХОСТА>:8080
```

Например: `http://192.168.1.100:8080`

### Шаг 4: Создание и подключение к комнате

**На хосте:**
1. Нажмите "Создать комнату"
2. Скопируйте код комнаты (например: ABC123)
3. Передайте код второму игроку

**На втором ПК:**
1. Нажмите "Присоединиться"
2. Введите код комнаты
3. Нажмите "Готов"

**На хосте:**
1. Нажмите "Готов"
2. Игра начнётся!

## Решение проблем

### "Комната не найдена"
- Убедитесь что оба компьютера в одной сети
- Проверьте что сервер запущен на хосте
- Проверьте код комнаты

### "Не удаётся подключиться"
- Проверьте файрвол на хосте (разрешите порт 8080)
- Убедитесь что IP адрес правильный
- Попробуйте перезапустить сервер

### Порт 8080 занят
Отредактируйте `server.mjs` и измените:
```javascript
const PORT = parseInt(process.argv[2]) || 8080; // измените на другой порт, например 3000
```

## Как это работает

1. **Сервер** (`server.mjs`) - Node.js приложение на порту 8080
   - Раздаёт статические файлы из `dist/`
   - Обрабатывает WebSocket соединения
   - Хранит состояние игры (authoritative server)

2. **Клиент** - React приложение
   - Подключается к серверу через WebSocket
   - Отправляет действия (play card, attack, end turn)
   - Получает обновления состояния

3. **Безопасность**
   - Вся игровая логика на сервере
   - Клиент не может читерить
   - Состояние синхронизируется в реальном времени

# 🔧 Устранение неполадок

## Проблема: "node: command not found"

**Решение:** Установите Node.js с официального сайта:
- https://nodejs.org (версия 18 или выше)

После установки перезапустите терминал.

---

## Проблема: "Cannot find module 'ws'"

**Решение:** Сервер автоматически устанавливает зависимости при первом запуске. Если ошибка повторяется, установите вручную:
```bash
npm install
```

Затем снова запустите:
```bash
node server.mjs
```

---

## Проблема: "Port 8080 is already in use"

**Решение:** Запустите сервер на другом порту:
```bash
node server.mjs 3000  # или любой другой свободный порт
```

Или остановите программу, использующую порт 8080.

---

## Проблема: Второй игрок не может подключиться

**Проверьте:**
1. Оба компьютера в одной сети (WiFi/ethernet)
2. Файрвол не блокирует порт 8080
3. IP адрес правильный (из консоли сервера)

**Как узнать IP:**
- **Windows:** `ipconfig` → найдите "IPv4 Address"
- **Linux/Mac:** `ifconfig` или `ip addr`

**Пример:**
Если ваш IP `192.168.1.100`, второй игрок открывает:
```
http://192.168.1.100:8080
```

---

## Проблема: "WebSocket connection failed"

**Решение:**
1. Убедитесь что сервер запущен
2. Проверьте консоль браузера (F12) на ошибки
3. Попробуйте перезагрузить страницу (F5)

---

## Проблема: Игра не загружается (белый экран)

**Решение:**
1. Откройте консоль браузера (F12)
2. Посмотрите ошибки
3. Попробуйте:
   - Очистить кэш (Ctrl+Shift+R)
   - Использовать другой браузер
   - Перезапустить сервер

---

## Проблема: "npm: command not found"

**Решение:** npm идёт в комплекте с Node.js. Установите Node.js:
- https://nodejs.org

---

## Проблема: Комната не видна в списке

**Решение:**
1. Убедитесь что оба клиента подключены к одному серверу
2. Обновите страницу (F5)
3. Проверьте что хост создал комнату

---

## Проблема: Игра зависла

**Решение:**
1. Перезагрузите страницу (F5)
2. Если не помогло - перезапустите сервер
3. Создайте новую комнату

---

## Общая рекомендация

Если ничего не помогает:
1. Удалите папку `node_modules`
2. Выполните `npm install`
3. Запустите `node server.mjs`

Если проблема сохраняется - создайте issue на GitHub с описанием проблемы и скриншотом консоли браузера (F12).

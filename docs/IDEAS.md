# 💡 Идеи для улучшений

## 🎮 Геймплей

### Новые механики
- [ ] **Система классов героев** (Воин, Маг, Жрец, Охотник, Разбойник, Шаман, Чернокнижник, Паладин, Друид)
  - Каждый класс имеет уникальную способность героя
  - Классовые карты (только для определённого класса)
  - Выбор класса перед игрой

- [ ] **Система колодостроения**
  - Редактор колод с фильтрами по классу, мане, типу
  - Сохранение колод в localStorage
  - Импорт/экспорт колод (коды)
  - Валидация колоды (максимум 2 копии обычной, 1 легендарной)

- [ ] **Ранговая система**
  - Ранги от Бронзы до Легенды
  - Очки рейтинга (MMR)
  - Сезонные награды
  - Таблица лидеров

- [ ] **Режим "Арена"**
  - Draft карт (выбор из 3 случайных)
  - 3 победы или 3 поражения
  - Награды в зависимости от побед

- [ ] **Система достижений**
  - Достижения за победы, убийства, использование карт
  - Награды (золото, карты, косметика)
  - Ежедневные/еженедельные задания

### Новые типы карт
- [ ] **Карты с выбором** (Choose One - как у Друидов)
  - При разыгрывании игрок выбирает один из двух эффектов
  
- [ ] **Трансформирующиеся карты**
  - Превращаются в другую карту при определённых условиях
  
- [ ] **Карты с перегрузкой** (Overload - как у Шаманов)
  - Мощный эффект, но блокируют ману на следующий ход
  
- [ ] **Карты с комбо** (Combo - как у Разбойников)
  - Усиленный эффект если это не первая карта в ходу
  
- [ ] **Места** (Locations)
  - Постоянные эффекты на поле
  - Можно "активировать" раз в ход

### Баланс
- [ ] **Система баланса**
  - Статистика побед по картам
  - Автоматическая настройка силы карт
  - Nerf/buff на основе данных

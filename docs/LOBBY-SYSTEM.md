# 🏰 Система лобби и комнат

## Как это работает

### Создание комнаты
1. В главном меню нажмите **"🌐 МУЛЬТИПЛЕЕР"**
2. Откроется экран лобби со списком доступных комнат
3. Нажмите **"➕ СОЗДАТЬ КОМНАТУ"**
4. Вы попадёте в комнату ожидания с уникальным кодом (например: `ABC123`)

### Ожидание игрока
- В комнате ожидания отображается:
  - **Код комнаты** (крупно, с кнопкой копирования)
  - **Список игроков** (вы как хост + ожидание второго игрока)
  - **Инструкция** как подключиться другу
- Кнопка **"НАЧАТЬ ИГРУ"** активна только когда второй игрок подключился

### Подключение к комнате
**Способ 1: По коду**
1. Друг открывает игру
2. Нажимает **"🌐 МУЛЬТИПЛЕЕР"**
3. В поле "ПРИСОЕДИНИТЬСЯ ПО КОДУ" вводит код комнаты
4. Нажимает **"ВОЙТИ"**

**Способ 2: Из списка**
1. Друг открывает игру
2. Нажимает **"🌐 МУЛЬТИПЛЕЕР"**
3. Видит вашу комнату в списке "ДОСТУПНЫЕ КОМНАТЫ"
4. Нажимает **"ВОЙТИ"** рядом с вашей комнатой

### Начало игры
- Когда оба игрока в комнате, хост нажимает **"🎮 НАЧАТЬ ИГРУ"**
- Игра начинается автоматически

## Технические детали

### Серверная часть (server.mjs)
- **WebSocket сервер** на порту 8080
- Хранит список комнат в памяти
- Автоматически обновляет список при создании/удалении комнат
- Транслирует список комнат всем подключённым клиентам

### Сообщения WebSocket

**Клиент → Сервер:**
```javascript
{ type: 'get_rooms' }              // Запрос списка комнат
{ type: 'create_room', playerName: 'Имя' }  // Создать комнату
{ type: 'join_room', roomId: 'ABC123', playerName: 'Имя' }  // Войти в комнату
{ type: 'start_game' }             // Начать игру (только хост)
```

**Сервер → Клиент:**
```javascript
{ type: 'room_list', rooms: [...] }        // Список комнат
{ type: 'room_created', roomId: 'ABC123' } // Комната создана
{ type: 'player_joined', playerName: 'Имя' } // Игрок вошёл
{ type: 'player_disconnected' }            // Игрок вышел
{ type: 'game_start', state: {...} }       // Игра началась
```

### Структура комнаты
```javascript
{
  id: 'ABC123',           // Уникальный код
  hostName: 'Игрок_1',    // Имя хоста
  guestName: 'Игрок_2',   // Имя гостя (null если нет)
  isFull: false,          // Заполнена ли комната
  playerCount: 1          // Количество игроков (0, 1, 2)
}
```

## Особенности

### Автоматическое обновление
- Список комнат обновляется в реальном времени
- Когда игрок выходит, комната автоматически удаляется
- Все клиенты получают обновления через WebSocket

### Безопасность
- Коды комнат генерируются случайно (6 символов)
- Только хост может начать игру
- Нельзя войти в заполненную комнату

### UX
- Кнопка копирования кода для быстрого分享
- Визуальная индикация статуса (ожидание/готов)
- Инструкция прямо в интерфейсе
- Кнопка "Выйти" для возврата в меню

## Отладка

### Проблемы и решения

**Комната не видна в списке:**
- Проверьте что сервер запущен (`node server.mjs`)
- Убедитесь что оба клиента подключены к одному серверу
- Обновите страницу (F5)

**Не удаётся подключиться:**
- Проверьте код комнаты (регистр не важен)
- Убедитесь что комната не заполнена
- Проверьте консоль браузера на ошибки WebSocket

**Игрок отключился:**
- Сервер автоматически удаляет комнату
- Другой игрок получает уведомление
- Можно создать новую комнату

# 🎨 PIXEL ART GUIDE — Карты Судьбы

## 1. Что сейчас не так

### Главное меню
- ❌ Эмодзи вместо спрайтов — выглядит дёшево
- ❌ Градиенты CSS — это НЕ пиксель-арт
- ❌ Звёзды через `border-radius: 50%` — сглаженные, не пиксельные
- ❌ Замок из `div`-ов с border — примитивно, не выглядит как pixel art
- ❌ Кнопки с градиентами — гладкие, без пиксельной структуры
- ❌ Шрифт подключён, но используется везде одинаково, без иерархии

### Игровой стол
- ❌ Поле боя — просто градиент зелёного, нет текстуры
- ❌ Карты — градиенты, скруглённые углы, нет пиксельной рамки
- ❌ Существа — эмодзи на градиентном фоне
- ❌ Герои — эмодзи, нет портретов
- ❌ Мана — круглые div-ы (сглаженные!)
- ❌ Колода — просто цветной прямоугольник
- ❌ Нет ощущения "настольной" игры

### Карты (CardComponent)
- ❌ Градиенты вместо плоских пиксельных цветов
- ❌ `border-radius` — скругление убивает пиксельность
- ❌ Эмодзи вместо спрайтов
- ❌ Rarity gem — круглый div (сглаженный)
- ❌ Нет настоящей пиксельной рамки карты

### Существа на поле (MinionComponent)
- ❌ Эмодзи вместо спрайтов
- ❌ Градиентный фон
- ❌ `border-radius` на кнопке
- ❌ Нет pixel-perfect рамки

### Коллекция
- ❌ Те же проблемы что и карты
- ❌ Нет пиксельного фона

### Экран результата
- ❌ Градиенты
- ❌ Эмодзи вместо спрайтов
- ❌ `animate-ping` — плавная анимация, не пиксельная

## 2. Как ДОЛЖНО выглядеть

### Размер пикселя
- **Базовый пиксель**: 4x4 CSS px (для мелких элементов)
- **Крупный пиксель**: 8x8 CSS px (для спрайтов героев, крупных элементов)
- Все координаты кратны базовому пикселю
- Никаких `border-radius` (кроме 0 или 2px для микро-скруглений)

### Палитра (32 цвета, тёплые фэнтези-тона)
```css
/* Основа */
--px-black: #1a1a2e;
--px-dark: #16213e;
--px-navy: #0f3460;
--px-blue: #2d6cdf;
--px-sky: #63b3ed;

/* Зелёные (стол, природа) */
--px-dgreen: #1b4332;
--px-green: #2d6a4f;
--px-lgreen: #52b788;
--px-mint: #95d5b2;

/* Красные (огонь, кровь) */
--px-dred: #6b0f1a;
--px-red: #d62828;
--px-lred: #f77f00;
--px-orange: #fcbf49;

/* Жёлтые/золотые (магия, редкость) */
--px-gold: #ffd60a;
--px-dgold: #b8860b;
--px-amber: #e09f3e;

/* Фиолетовые (магия, эпик) */
--px-dpurple: #3c096c;
--px-purple: #7b2cbf;
--px-lpurple: #c77dff;

/* Нейтральные */
--px-white: #f8f9fa;
--px-lgray: #adb5bd;
--px-gray: #6c757d;
--px-dgray: #343a40;
--px-brown: #6b4226;
--px-dbrown: #3e2013;
--px-skin: #e8beac;
--px-wood: #8b5e3c;
```

### image-rendering
```css
* { image-rendering: pixelated; image-rendering: crisp-edges; }
```

### Шрифт
- **Press Start 2P** — основной (заголовки, кнопки)
- Размеры: 6px, 8px, 10px, 12px, 16px (кратно 2)
- Никаких `font-weight: bold` (шрифт уже жирный)

### Спрайты
- Все существа — попиксельные спрайты 32x32 (масштаб 2x = 64x64 CSS px)
- Герои — спрайты 48x48 (масштаб 2x = 96x96 CSS px)
- Карты — пиксельная рамка 3px, внутренние элементы без скруглений
- Кнопки — пиксельные рамки с "вдавленными" углами

### Анимации
- Покадровые (steps), НЕ плавные tween
- `animation-timing-function: steps(4)` для движения
- Мигание — `steps(1)` (без промежуточных кадров)
- Частицы — пиксельные квадраты 2x2 или 4x4

## 3. Референсы

### Общее ощущение
- **Hearthstone** (оригинальный) — тёплые цвета, деревянный стол
- **Slay the Spire** — пиксельные карты, чёткие рамки
- **Crypt of the NecroDancer** — пиксельный UI, яркие цвета
- **Loop Hero** — пиксельные спрайты существ, тёплая палитра

### Стол
- Как деревянная доска с текстурой (пиксельная)
- Зелёное сукно в центре с пиксельным узором
- Золотые/деревянные рамки по краям

### Карты
- Толстая пиксельная рамка (3-4px)
- Цвет рамки зависит от редкости: серый/синий/фиолетовый/золотой
- Внутри — плоские цвета, без градиентов
- Арты — попиксельные спрайты

### Существа
- 32x32 пиксельные спрайты
- Каждый — уникальный, узнаваемый силуэт
- Огненный имп — маленький красный бес с рогами
- Серебряный рыцарь — белый с щитом
- Пустотный червь — огромный тёмный змей

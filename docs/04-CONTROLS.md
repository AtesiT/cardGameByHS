# Управление в игре

## Главное меню
- **ИГРА ВДВОЁМ** — начать hot-seat игру
- **ПРОТИВ AI** — начать игру против компьютера
- **КОЛЛЕКЦИЯ** — просмотреть все карты

## Игровой стол

### Разыгрывание карт
1. Навести курсор на карту в руке
2. Кликнуть для розыгрыша
3. Если карта требует цель — выбрать цель на поле
4. ESC — отменить выбор цели

### Атака
1. Кликнуть по своему существу (подсвечивается зелёным, если может атаковать)
2. Кликнуть по цели:
   - Вражеское существо — атаковать его
   - Вражеский герой — атаковать героя
3. ESC — отменить выбор атакующего

### Оружие
- Кликнуть по оружию для атаки героем
- Выбрать цель

### Способность героя
- Кнопка ✨ (стоимость 2 маны)
- Эффект: 1 урон вражескому герою + 2 HP вашему герою
- 1 раз за ход

### Завершение хода
- Кнопка "КОНЕЦ ХОДА" (красная, справа)
- Передаёт ход противнику

### Эмоции
- Кнопка 💬
- 8 эмоций: 👋🙏👏😅😈😂😮😢
- Противник видит эмоцию

### Горячие клавиши
- **ESC** — отменить выбор цели/атакующего

## Коллекция
- Фильтры по типу (существа/заклинания/оружия)
- Фильтры по редкости
- Клик по карте — подробная информация

## Экран результата
- **ИГРАТЬ СНОВА** — начать новую партию
- **В МЕНЮ** — вернуться в главное меню

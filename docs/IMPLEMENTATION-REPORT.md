#### Способности героев по классам:

**⚔️ Воин (Warrior)**
- Способность: "Вооружиться"
- Эффект: +2 брони
- Стратегия: Защитный класс, накапливает броню для поглощения урона

**🔮 Маг (Mage)**
- Способность: "Огненный взрыв"
- Эффект: 1 урон вражескому герою
- Стратегия: Агрессивный класс, постоянный небольшой урон

**✨ Жрец (Priest)**
- Способность: "Малое исцеление"
- Эффект: +2 здоровья герою
- Стратегия: Контрольный класс, поддерживает здоровье

**🏹 Охотник (Hunter)**
- Способность: "Выстрел"
- Эффект: 2 урона вражескому герою
- Стратегия: Агрессивный класс, прямой урон в лицо

**🗡️ Разбойник (Rogue)**
- Способность: "Кинжалы"
- Эффект: Экипировать оружие 1/1
- Стратегия: Темпо класс, использует оружие для торговли

**⚡ Шаман (Shaman)**
- Способность: "Тотем"
- Эффект: Призвать случайный тотем (4 варианта):
  - Тотем лечения (0/2)
  - Тотем огня (1/1)
  - Каменный тотем (0/3, Провокация)
  - Тотем гнева (2/1)
- Стратегия: Ценностный класс, накапливает существ на поле

**😈 Чернокнижник (Warlock)**
- Способность: "Жизненная сила"
- Эффект: 2 урона себе, взять 1 карту
- Стратегия: Комбо класс, жертвует здоровьем ради карт

**🛡️ Паладин (Paladin)**
- Способность: "Воззвание"
- Эффект: Призвать Серебряного новобранца 1/1
- Стратегия: Широкий класс, заполняет поле существами

**🌿 Друид (Druid)**
- Способность: "Метаморфоза"
- Эффект: +1 броня (временный бафф атаки упрощён)
- Стратегия: Гибкий класс, адаптация к ситуации

## 🎮 Как это работает в игре

### Выбор класса
1. В главном меню нажмите "👤 КЛАСС: [текущий класс]"
2. Выберите один из 9 классов
3. Каждый класс имеет уникальную способность

### Использование способности
1. Нажмите кнопку "✨ 2💎" (стоимость 2 маны)
2. Способность активируется автоматически
3. Эффект зависит от выбранного класса

### Система брони
- Броня отображается рядом со здоровьем (🛡 иконка)
- При получении урона сначала теряется броня
- Когда броня заканчивается, урон идёт по здоровью
- Броня не имеет максимума (может накапливаться)

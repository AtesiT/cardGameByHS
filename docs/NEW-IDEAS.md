# 💡 Новые идеи для улучшений

## 🎮 Геймплей

### Режимы игры
- [ ] **Режим "Выживание"** - бесконечные волны врагов с нарастающей сложностью
- [ ] **Режим "Гонка"** - кто первый нанесёт 50 урона герою противника
- [ ] **Режим "Блиц"** - 30 секунд на ход, иначе автоматический пропуск
- [ ] **Режим "Draft"** - выбор карт из случайных наборов перед игрой
- [ ] **Режим "Арена"** - 12 игр с нарастающими наградами
- [ ] **Режим "Башня"** - прохождение этажей с боссами
- [ ] **Режим "Квесты"** - ежедневные задания с наградами
- [ ] **Режим "Дуэль"** - 1v1 с особыми правилами (только заклинания, только существа)

### Новые механики
- [ ] **Система комбо** - бонусы за последовательное разыгрывание карт одного типа
- [ ] **Система синергии** - карты усиливают друг друга (например, все звери получают +1/+1)
- [ ] **Система усталости** - карты становятся слабее при повторном использовании
- [ ] **Система морали** - выбор между добром и злом влияет на доступные карты
- [ ] **Система погоды** - случайные эффекты каждый ход (дождь, солнце, буря)
- [ ] **Система времени суток** - разные эффекты днём и ночью
- [ ] **Система ресурсов** - дерево, камень, золото для создания карт
- [ ] **Система крафта** - создание новых карт из материалов
- [ ] **Система эволюции** - существа могут эволюционировать в более сильные формы
- [ ] **Система мутаций** - случайные изменения характеристик существ

### Новые типы карт
- [ ] **Карты-ловушки** - активируются когда противник разыгрывает карту
- [ ] **Карты-ауры** - постоянные эффекты для всех существ
- [ ] **Карты-порталы** - телепортация существ между сторонами поля
- [ ] **Карты-проклятия** - негативные эффекты для противника
- [ ] **Карты-благословения** - позитивные эффекты для игрока
- [ ] **Карты-ритуалы** - мощные эффекты ценой здоровья
- [ ] **Карты-призывы** - временные существа на 1 ход
- [ ] **Карты-трансформации** - превращение существ в другие
- [ ] **Карты-копии** - копирование существ противника
- [ ] **Карты-жертвы** - уничтожение своих существ для мощных эффектов

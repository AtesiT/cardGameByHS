## Найденные и исправленные баги

### Баг 1: Усталость не учитывает броню
**Где:** `src/engine/GameEngine.ts`, строка 97  
**Проблема:** При усталости (когда колода пуста) урон наносился напрямую здоровью, игнорируя броню.  
**Исправление:** Заменён прямой вызов `player.heroHealth -= player.fatigue` на `dealDamageToHero(state, playerIndex, player.fatigue)`  
**Влияние:** Теперь усталость правильно поглощается бронёй перед нанесением урона здоровью.

### Баг 2: Заклинания не учитывают броню при уроне герою
**Где:** `src/engine/GameEngine.ts`, строка 234  
**Проблема:** Заклинания с `spellTarget: 'any'` при выборе цели-героя наносили урон напрямую, игнорируя броню.  
**Исправление:** Заменён прямой вызов `state.players[targetPlayerIdx].heroHealth -= def.spellDamage` на `dealDamageToHero(state, targetPlayerIdx, def.spellDamage)`  
**Влияние:** Теперь заклинания правильно взаимодействуют с бронёй.

### Баг 3: Урон заклинаниями герою (когда нет существ) не учитывает броню
**Где:** `src/engine/GameEngine.ts`, строка 249  
**Проблема:** Заклинания с `spellTarget: 'none'` (например, Молния) при отсутствии вражеских существ наносили урон герою напрямую, игнорируя броню.  
**Исправление:** Заменён прямой вызов `opponent.heroHealth -= def.spellDamage` на `dealDamageToHero(state, opponentIdx, def.spellDamage)`  
**Влияние:** Теперь случайный урон заклинаний правильно поглощается бронёй.

### Баг 4: Дублирование переменной opponentIdx в функции attack
**Где:** `src/engine/GameEngine.ts`, строка 382  
**Проблема:** Переменная `opponentIdx` объявлялась дважды - сначала на строке 357, потом повторно на строке 382 внутри блока `if (targetIsHero)`. Это могло вызвать проблемы с областью видимости.  
**Исправление:** Убрано дублирование объявления переменной, используется существующая переменная из внешней области.  
**Влияние:** Код стал чище и безопаснее, нет потенциальных конфликтов переменных.

### Баг 5: Lifesteal не учитывает фактический урон
**Где:** `src/engine/GameEngine.ts`, строка 387  
**Проблема:** Lifesteal (кража жизни) восстанавливал здоровье на основе максимальной атаки, а не фактического урона. Если часть урона поглощалась бронёй, игрок всё равно получал полное лечение.  
**Исправление:** Теперь Lifesteal вычисляет фактический урон как `(healthBefore - opponent.heroHealth) + (armorBefore - opponent.armor)` и лечит только на эту сумму.  
**Влияние:** Lifesteal теперь работает корректно - лечит только на фактически нанесённый урон, а не на максимальный.

## Технические детали

### Функция dealDamageToHero
```typescript
function dealDamageToHero(state: GameState, playerIndex: number, damage: number): void {
  const player = state.players[playerIndex];
  let remainingDamage = damage;
  
  // First, absorb damage with armor
  if (player.armor > 0) {
    const armorAbsorbed = Math.min(player.armor, remainingDamage);
    player.armor -= armorAbsorbed;
    remainingDamage -= armorAbsorbed;
    if (armorAbsorbed > 0) {
      state.log.push(`${player.name} теряет ${armorAbsorbed} брони`);
    }
  }
  
  // Then, apply remaining damage to health
  if (remainingDamage > 0) {
    player.heroHealth -= remainingDamage;
    state.log.push(`${player.name} получает ${remainingDamage} урона (${player.heroHealth} HP, ${player.armor} брони)`);
  }
}
```

### Логика работы:
1. Сначала урон поглощается бронёй (если она есть)
2. Затем остаток урона применяется к здоровью
3. Каждое действие логируется для отладки

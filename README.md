# ⚔️ Карты Судьбы — Пиксельная карточная игра

Карточная игра для двоих, вдохновлённая Hearthstone, с пиксельной графикой, анимациями и 8-bit звуками.

![Pixel Card Game](https://img.shields.io/badge/style-pixel_art-ff69b4)
![Cards](https://img.shields.io/badge/cards-30-blue)
![Mechanics](https://img.shields.io/badge/mechanics-all-green)

## 🎮 Описание

«Карты Судьбы» — это полноценная карточная игра с:
- **65+ уникальными картами** (30 базовых + 35 классовых)
- **9 классов героев** с уникальными способностями (Воин, Маг, Жрец, Охотник, Разбойник, Шаман, Чернокнижник, Паладин, Друид)
- **Всеми ключевыми механиками**: Провокация, Рывок, Божественный щит, Яд, Боевой клич, Смертельный хрип, Ветер ветра, Кража жизни
- **Пиксельным визуалом** в стиле Stardew Valley с анимациями
- **Эффектами частиц** для заклинаний (огонь, лёд, молнии)
- **8-bit звуками** через Web Audio API
- **Системой эмоций** (как в Hearthstone)
- **AI противником** для одиночной игры
- **Системой прогресса**: ранги, достижения, статистика
- **Редактором колод** с сохранением в localStorage
- **Режимом hot-seat** для игры вдвоём на одном устройстве
- **Мультиплеером** по локальной сети

## 🚀 Быстрый запуск

### Просто запусти!

**Linux/Mac:**
```bash
./start.sh
```

**Windows:**
```bash
start.bat
```

**Или напрямую:**
```bash
node server.mjs
```

**С указанием порта:**
```bash
node server.mjs 3000  # запустить на порту 3000
```

**ВСЁ!** При первом запуске сервер **автоматически установит все зависимости**. Никаких `npm install`, никаких `npm run build`. Сервер сам соберёт проект и запустится на порту **8080**.

Откройте браузер: `http://localhost:8080`

### Первый запуск
При первом запуске вы увидите:
```
╔═══════════════════════════════════════════════════════════╗
║                                                           ║
║   🔧 Первый запуск! Устанавливаю зависимости...          ║
║                                                           ║
║   Это займёт 1-2 минуты. Пожалуйста, подождите...       ║
║                                                           ║
╚═══════════════════════════════════════════════════════════╝
```

Подождите 1-2 минуты пока установятся зависимости. При последующих запусках сервер стартует мгновенно!

### Мультиплеер по локальной сети

Сервер автоматически покажет ваш IP адрес в консоли:

```
╔═══════════════════════════════════════════════════════════╗
║   ⚔  КАРТЫ СУДЬБЫ - Сервер запущен!  ⚔                  ║
║                                                           ║
║   Локальный адрес: http://localhost:8080                  ║
║   Сетевой адрес:   http://192.168.1.100:8080             ║
║                                                           ║
╚═══════════════════════════════════════════════════════════╝
```

### Как играть
1. **Хост** запускает `node server.mjs` и открывает `http://localhost:8080`
2. **Второй игрок** открывает `http://<IP_ХОСТА>:8080` (адрес из консоли)
3. Хост нажимает "🌐 МУЛЬТИПЛЕЕР" → "➕ СОЗДАТЬ КОМНАТУ"
4. Копирует код комнаты и отправляет другу
5. Друг нажимает "🌐 МУЛЬТИПЛЕЕР" → вводит код → "ВОЙТИ"
6. Хост нажимает "🎮 НАЧАТЬ ИГРУ"

## 🎯 Режимы игры

### Игрок vs AI
Сражайтесь против искусственного интеллекта. AI играет агрессивно, разыгрывает сильные карты и торгует существами.

### Hot-seat (Вдвоём)
Играйте с другом на одном устройстве. После каждого хода устройство передаётся другому игроку (рука скрывается).

## 🎮 Управление

### В игре:
- **Клик по карте в руке** — разыграть (или выбрать цель для заклинания)
- **Клик по своему существу** — выбрать атакующего
- **Клик по вражескому существу/герою** — атаковать выбранным
- **ESC** — отменить выбор
- **Конец хода** — кнопка справа
- **Способность героя** — ✨ (2 маны, 1 урон + 2 лечение)
- **Эмоции** — 💬 кнопка

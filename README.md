# ⚔️ Карты Судьбы — Пиксельная карточная игра

Карточная игра для двоих, вдохновлённая Hearthstone, с пиксельной графикой, анимациями и 8-bit звуками.

## 🎮 Описание

«Карты Судьбы» — это полноценная карточная игра с:
- **30 уникальными картами** (15 существ, 10 заклинаний, 5 оружий)
- **Всеми ключевыми механиками**: Провокация, Рывок, Божественный щит, Яд, Боевой клич, Смертельный хрип, Ветер ветра, Кража жизни
- **Пиксельным визуалом** с анимациями
- **8-bit звуками** через Web Audio API
- **Системой эмоций** (как в Hearthstone)
- **AI противником** для одиночной игры
- **Режимом hot-seat** для игры вдвоём на одном устройстве

## 🚀 Быстрый запуск

### Одиночная игра / Hot-seat (один компьютер)
```bash
npm install
npm run dev
```
Откройте http://localhost:5173

### Мультиплеер по локальной сети (2 компьютера)
```bash
# 1. Сборка клиента
npm run build

# 2. Запуск сервера на порту 8080
node server.js

# 3. На первом ПК откройте http://localhost:8080
# 4. На втором ПК откройте http://<IP_ПЕРВОГО_ПК>:8080
```

**Как играть:**
1. Хост нажимает "🌐 МУЛЬТИПЛЕЕР" → "➕ СОЗДАТЬ КОМНАТУ"
2. Копирует код комнаты и отправляет другу
3. Друг открывает игру → "🌐 МУЛЬТИПЛЕЕР" → вводит код → "ВОЙТИ"
4. Хост нажимает "🎮 НАЧАТЬ ИГРУ"

Сервер автоматически раздаёт собранные файлы и обрабатывает WebSocket соединения. Система лобби показывает список комнат и позволяет подключаться по коду.

## 📋 Системные требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Поддержка Web Audio API
- JavaScript включён

## 🎯 Режимы игры

### Игрок vs AI
Сражайтесь против искусственного интеллекта. AI играет агрессивно, разыгрывает сильные карты и торгует существами.

### Hot-seat (Вдвоём)
Играйте с другом на одном устройстве. После каждого хода устройство передаётся другому игроку (рука скрывается).

## 🎮 Управление

### В игре:
- **Клик по карте в руке** — разыграть (или выбрать цель для заклинания)
- **Клик по своему существу** — выбрать атакующего
- **Клик по вражескому существу/герою** — атаковать выбранным
- **ESC** — отменить выбор
- **Конец хода** — кнопка справа
- **Способность героя** — ✨ (2 маны, 1 урон + 2 лечение)
- **Эмоции** — 💬 кнопка

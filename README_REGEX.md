# 🎯 Пользовательский движок регулярных выражений

Полноценный движок регулярных выражений, реализованный с нуля на Python без использования встроенных библиотек `re` или `regex`.

## 📋 Возможности

### Поддерживаемый синтаксис

| Синтаксис | Описание | Пример |
|-----------|----------|--------|
| `abc` | Литералы | `abc` совпадает с "abc" |
| `.` | Любой символ | `a.c` совпадает с "abc", "axc" |
| `[abc]` | Класс символов | `[abc]` совпадает с "a", "b" или "c" |
| `[^abc]` | Негация класса | `[^abc]` совпадает с любым символом кроме "a", "b", "c" |
| `*` | Ноль или более (жадный) | `a*` совпадает с "", "a", "aa", ... |
| `+` | Один или более (жадный) | `a+` совпадает с "a", "aa", ... |
| `?` | Ноль или один (жадный) | `a?` совпадает с "" или "a" |
| `*?` | Ноль или более (ленивый) | `a*?` минимальное совпадение |
| `+?` | Один или более (ленивый) | `a+?` минимальное совпадение |
| `??` | Ноль или один (ленивый) | `a??` минимальное совпадение |
| `()` | Группировка | `(ab)+` совпадает с "ab", "abab", ... |
| `\|` | Альтернатива | `a\|b` совпадает с "a" или "b" |
| `\\` | Экранирование | `\\.` совпадает с литералом "." |

### Использование

```python
from regex_engine import regex_match

# Простые совпадения
print(regex_match("abc", "abc"))  # True
print(regex_match("abc", "abcd"))  # True (совпадение в любом месте)
print(regex_match("abc", "xabc"))  # True

# Квантификаторы
print(regex_match("a*", ""))      # True (ноль совпадений)
print(regex_match("a*", "aaa"))   # True
print(regex_match("a+", ""))      # False (нужен минимум один)
print(regex_match("a+", "a"))     # True

# Классы символов
print(regex_match("[abc]", "b"))  # True
print(regex_match("[^abc]", "d")) # True
print(regex_match("[^abc]", "a")) # False

# Группы и альтернативы
print(regex_match("(ab)+", "abab"))     # True
print(regex_match("(a|b)+", "abba"))    # True

# Точка (любой символ)
print(regex_match(".", "x"))      # True
print(regex_match(".", ""))       # False

# Экранирование
print(regex_match("\\.", "."))    # True (литерал точки)
print(regex_match("\\.", "a"))    # False

# Сложные паттерны
print(regex_match("a*b", "b"))    # True
print(regex_match("a*b", "aab"))  # True
print(regex_match("a*a", "aaa"))  # True (бэктрекинг)
```

### Использование класса RegexEngine

```python
from regex_engine import RegexEngine, RegexError

try:
    engine = RegexEngine("(a|b)+c")
    
    if engine.match("abc"):
        print("Совпадение найдено!")
    
    if engine.match("bbc"):
        print("Еще одно совпадение!")
        
except RegexError as e:
    print(f"Ошибка в паттерне: {e}")
```

## 🛡️ Защита от ReDoS

Движок защищен от catastrophic backtracking (ReDoS) через мемоизацию:

```python
# Этот паттерн вызвал бы экспоненциальное время в наивной реализации
# Но наш движок справляется благодаря кэшированию
pattern = "(a+)+b"
text = "a" * 30 + "c"

# Выполняется за ~50мс вместо минут/часов
result = regex_match(pattern, text)  # False
```

## 🏗️ Архитектура

### Компоненты

1. **Парсер** - преобразует строку паттерна в AST
2. **AST** - древовидное представление паттерна
3. **Генераторы** - реализуют бэктрекинг
4. **Кэш** - мемоизация для оптимизации

### Типы узлов AST

```python
('empty',)                          # Пустой паттерн
('literal', 'a')                    # Литерал
('dot',)                            # Точка (любой символ)
('char_class', chars, negate)       # Класс символов
('concat', [nodes])                 # Конкатенация
('alternation', left, right)        # Альтернатива
('group', node)                     # Группа
('star', node, lazy)                # Квантификатор *
('plus', node, lazy)                # Квантификатор +
('question', node, lazy)            # Квантификатор ?
```

## 🐛 Обработка ошибок

Движок предоставляет понятные сообщения об ошибках:

```python
from regex_engine import RegexEngine, RegexError

# Незакрытая группа
try:
    RegexEngine("(abc")
except RegexError as e:
    print(e)  # "Незакрытая группа"

# Квантификатор без операнда
try:
    RegexEngine("*abc")
except RegexError as e:
    print(e)  # "Квантификатор без операнда: *"

# Незакрытый класс символов
try:
    RegexEngine("[abc")
except RegexError as e:
    print(e)  # "Незакрытый класс символов"
```

## 🎓 Ограничения

### Не поддерживается

- Обратные ссылки (`\1`, `\2`)
- Lookahead/lookbehind (`(?=...)`, `(?<=...)`)
- Named groups (`(?P<name>...)`)
- Unicode категории (`\p{L}`)
- Флаги (`i`, `m`, `s`)

### Почему?

Эти возможности требуют значительного усложнения архитектуры:
- Обратные ссылки требуют сохранения захваченных групп
- Lookahead/lookbehind требуют двунаправленного сопоставления
- Named groups требуют дополнительного API
- Unicode категории требуют таблиц символов
- Флаги требуют дополнительного состояния

Эти возможности могут быть добавлены в будущих версиях.

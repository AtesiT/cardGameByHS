# ⚔️ КАРТЫ СУДЬБЫ - Инструкция по запуску

## 🎯 Самый простой способ

### Для Windows:
1. Дважды кликните на `start.bat`
2. Откроется браузер автоматически
3. Играйте!

### Для Linux/Mac:
```bash
chmod +x start.sh
./start.sh
```

### Или вручную:
```bash
node server.js
```

---

## 🌐 Мультиплеер по локальной сети

### Шаг 1: Запустите сервер
```bash
node server.js
```

Вы увидите:
```
╔═══════════════════════════════════════════════════════════╗
║   ⚔  КАРТЫ СУДЬБЫ - Сервер запущен!  ⚔                  ║
║                                                           ║
║   Локальный адрес: http://localhost:8080                  ║
║   Сетевой адрес:   http://192.168.1.100:8080             ║
║                                                           ║
╚═══════════════════════════════════════════════════════════╝
```

### Шаг 2: Подключитесь
- **Первый игрок (хост):** откройте `http://localhost:8080`
- **Второй игрок:** откройте `http://192.168.1.100:8080` (IP из консоли)

### Шаг 3: Создайте комнату
1. Хост нажимает **"🌐 МУЛЬТИПЛЕЕР"**
2. Нажимает **"➕ СОЗДАТЬ КОМНАТУ"**
3. Копирует код (например: `ABC123`)
4. Отправляет код другу

### Шаг 4: Подключитесь
1. Второй игрок нажимает **"🌐 МУЛЬТИПЛЕЕР"**
2. Вводит код `ABC123`
3. Нажимает **"ВОЙТИ"**

### Шаг 5: Начните игру
1. Хост видит что второй игрок подключился
2. Нажимает **"🎮 НАЧАТЬ ИГРУ"**
3. Игра начинается!

## 📋 Требования

- **Node.js 18+** - скачать: https://nodejs.org
- **Браузер** - Chrome, Firefox, Edge, Safari
- **Локальная сеть** - оба компьютера в одной сети (WiFi или кабель)

---

## ❓ Проблемы?

### "node: command not found"
→ Установите Node.js: https://nodejs.org

### "Port 8080 is already in use"
→ Измените порт в `server.js`:
```javascript
const PORT = 8080; // измените на 3000
```

### Второй игрок не может подключиться
→ Проверьте:
1. Оба в одной сети
2. Файрвол не блокирует порт 8080
3. IP адрес правильный (из консоли)

### Подробное руководство по проблемам
→ См. `docs/TROUBLESHOOTING.md`

## 🎮 Режимы игры

### 1. Одиночная игра (vs AI)
- Играйте против компьютера
- Выберите колоду в меню
- Отлично для тренировки

### 2. Hot-seat (2 игрока на одном ПК)
- Передавайте устройство друг другу
- Экран скрывается между ходами
- Не нужна сеть

### 3. Мультиплеер (2 ПК в локальной сети)
- Играйте с другом по сети
- Создавайте комнаты
- Видите действия друг друга в реальном времени

## 💡 Советы

1. **Для лучшей производительности** используйте Chrome или Firefox
2. **Для мультиплеера** используйте проводное подключение (стабильнее)
3. **Для одиночной игры** можно просто открыть `index.html` из папки `dist/`

### Тест 2: Вложенные квантификаторы


**Анализ:** Мемоизация кэширует результаты для каждого `(a*)`, предотвращая экспоненциальный рост.

## 🔍 Детальный анализ найденных багов

### Критические баги (5)

1. **Неправильная логика `_match_rest()` (v1.0)**
   - **Симптом:** Квантификаторы не работали с последующими паттернами
   - **Причина:** Функция проверяла только конец текста, а не возможность сопоставления
   - **Исправление:** Переписана логика с использованием генераторов

2. **Отсутствие бэктрекинга (v1.1)**
   - **Симптом:** `a*a` на `aaa` не совпадало
   - **Причина:** Жадный режим просто возвращал самую дальнюю позицию
   - **Исправление:** Реализован генераторный подход с перебором вариантов

3. **ReDoS уязвимость (v1.0-v1.2)**
   - **Симптом:** `(a+)+b` на длинных строках зависало
   - **Причина:** Экспоненциальный рост количества вариантов
   - **Исправление:** Добавлена мемоизация через кэш

4. **Бесконечные циклы с пустыми совпадениями (v1.2)**
   - **Симптом:** `(a?)*` мог зациклиться
   - **Причина:** Квантификатор не делал прогресс
   - **Исправление:** Проверка `next_pos == current_pos`

5. **Неправильная работа concat (v1.0-v1.1)**
   - **Симптом:** `a*b` на `aab` не работало
   - **Причина:** Неправильная обработка позиций в конкатенации
   - **Исправление:** Рекурсивный подход с правильной передачей позиций

### Средние баги (7)

1. Неправильная обработка альтернативы (v1.0)
2. Проблема с пустым паттерном (v1.0)
3. Проблема с ленивым режимом (v1.1)
4. Отсутствие мемоизации (v1.2)
5. Низкая производительность генераторов (v1.2)
6. Неполная обработка ошибок парсинга (v1.0-v1.2)
7. Дублирование переменных (v1.1)

## 🎓 Извлеченные уроки

### 1. Важность правильного бэктрекинга
**Проблема:** Первая реализация не имела настоящего бэктрекинга  
**Решение:** Генераторный подход позволяет перебирать все варианты  
**Урок:** Бэктрекинг - это не просто откат, а перебор всех возможных путей

### 2. Защита от ReDoS критична
**Проблема:** Паттерны с вложенными квантификаторами вызывали экспоненциальное время  
**Решение:** Мемоизация результатов через кэш  
**Урок:** Любой движок регулярных выражений должен быть защищен от ReDoS

### 3. Пустые совпадения - источник багов
**Проблема:** Квантификаторы могли зацикливаться на пустых совпадениях  
**Решение:** Проверка прогресса (`next_pos == current_pos`)  
**Урок:** Всегда проверяйте, что квантификатор делает прогресс

### 4. Генераторы vs рекурсия
**Проблема:** Рекурсивный подход сложен для бэктрекинга  
**Решение:** Генераторы естественно поддерживают перебор вариантов  
**Урок:** Генераторы - мощный инструмент для задач с перебором

### 5. Мемоизация спасает производительность
**Проблема:** Повторные вычисления одних и тех же подпаттернов  
**Решение:** Кэширование результатов по `(node_id, position)`  
**Урок:** Мемоизация может превратить экспоненциальный алгоритм в линейный
